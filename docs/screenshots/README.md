# Screenshots

Take these with the app running (`npm run dev` + the API), browser window about 1440 px wide,
and save them here with these names so the report and slides can reference them:

| File | Page | What to show |
|---|---|---|
| `home.png` | `/` (signed in) | Hero with "Top pick for you", red rating, match badge |
| `home-picks.png` | `/` scrolled | "Top picks for you" staggered row with "Because you liked" |
| `detail.png` | `/movie/1` | Title block, meta row, poster, red icon tabs |
| `detail-related.png` | `/movie/1` scrolled | Quote strip + red "Related Movies" carousel |
| `for-you.png` | `/for-you` | Grid with match %, reasons and quick star ratings |
| `under-the-hood.png` | `/under-the-hood` | "Same user, different models" comparison |
| `results-table.png` | `/under-the-hood` scrolled | Offline evaluation table |
| `browse.png` | `/browse?genre=Animation&decade=1990` | Filters, chips, poster grid |
| `onboarding.png` | `/welcome` | Genre chips and favourite-movie picker |
| `light-theme.png` | any page | The light theme |
| `mobile.png` | any page at phone width (DevTools device mode) | Responsive layout |

Tip: add a TMDB key first (see the main README) so the screenshots show real posters.
